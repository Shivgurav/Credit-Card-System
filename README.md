# Credit Card Management System

A microservices-based Credit Card Management System developed using Spring Boot and React.

## Features
- User Authentication
- Credit Card Management
- Transaction Tracking
- API Gateway
- Service Registry
- Microservice Architecture

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Cloud
- Eureka Server

### Frontend
- React.js

### Database
- MySQL
